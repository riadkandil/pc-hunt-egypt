# PC component stores in Egypt (websites)

Compiled 2026-11-25. Every online store found that sells PC components (CPUs, GPUs, motherboards, RAM, SSDs, PSUs, cases, coolers), including stores where parts are not the main business.

**How this list was built**

- Main source: the store directory of [Qarenly](https://qarenly.com/en/store) (formerly eg-pc.com), an Egyptian PC-hardware price-comparison site tracking 112 stores. Each store's website was read from the "Go to site" link on one of its Qarenly product offers (so the domain is the one the store actually sells from).
- Added: stores and merchants seen on [EGPrices](https://www.egprices.com/en/category/computers/components) and [Pricena](https://eg.pricena.com/en/computers/computer-parts), plus web searches (marketplaces, server parts, classifieds).
- **Parts seen** = component types found among the products Qarenly listed for that store on its store page (a sample of up to ~70 products, keyword-matched), so it is a rough indicator, not the store's full range. An empty cell means none of the sampled product names matched, not that the store sells no parts.
- Grouping (specialist / chain / ...) is a first pass from the sampled products and store type; verify while analysing.

## Ideas for the analysis

- Scrape one product set (e.g. RTX 5060 / 5070, Ryzen 5 7600, 32 GB DDR5, 1 TB NVMe) from every group-A store and compare price, stock, warranty and shipping.
- Qarenly product pages already aggregate offers per product (`qarenly.com/en/product/<category>:<brand>:<model>`), which is the fastest way to get cross-store prices.
- Record per store: platform (Shopify / WooCommerce / Magento / custom), branches, payment (COD, installments, InstaPay), PC builder tool, warranty policy.
